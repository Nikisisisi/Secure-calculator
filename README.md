# Secure Calculator

Учебный проект по безопасной разработке студентов Обухова Никиты и Лапшиной Дарьи.

## Описание

Secure Calculator — API-калькулятор на FastAPI с веб-интерфейсом.

Поддерживаемые операции:

- сложение
- вычитание
- умножение
- деление
- обработка деления на ноль

## Технологии

- Python 3.13
- FastAPI
- Uvicorn
- Pytest
- Docker
